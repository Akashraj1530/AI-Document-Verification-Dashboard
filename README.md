# AI-Document-Verification-Dashboard

A web-based AI Document Verification Dashboard for automatically extracting and verifying important information from vendor and business documents using OCR and Python.

## 🌐 Live Demo

👉 [Open AI Document Verification Dashboard](https://ai-document-verification-dashboard-production.up.railway.app/)

## 💻 GitHub Repository

This repository contains the source code of the AI Document Verification Dashboard.

👉 [View GitHub Repository](https://github.com/Akashraj1530/AI-Document-Verification-Dashboard)

## 🚀 Features

- Upload Vendor and Business Documents
- OCR-based Text Extraction
- Automatic Document Verification
- Company Name Validation
- Email Validation
- Phone Number Validation
- GST Number Validation
- VERIFIED / REJECTED Status
- Verification Remarks
- Verification Dashboard
- Document Processing
- Railway Cloud Deployment

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Tesseract OCR
- pdf2image
- Poppler
- Gunicorn
- Docker
- Railway
